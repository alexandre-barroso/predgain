# Probability events and textual order in a sentence-processing benchmark

This repository contains original verification code for the accompanying finite benchmark audit. It reconstructs two released surprisal columns, checks the identity of preceding words, reconstructs four eye-time aggregates, and evaluates first-fixation and first-pass prediction. A crossed position/predecessor comparison separates changes in complete-model error from changes in the incremental value of current and preceding surprisal against matched covariate-only references. All adverse content-word and partition comparisons are retained.

**Raw data, source scripts, reference full texts and model weights are not included.** Full reproduction depends on separately authorized access to the exact inputs below. A synthetic test pass does not reproduce the empirical findings. No public software license or hosted release has been authorized for this local package.

## Environment and inputs

The development run used Python 3.12.14 on CPU, with the versions in `requirements-models.txt`. Create a local virtual environment and install those requirements. Model inference requires PyTorch and Transformers; synthetic tests need only `requirements.txt`. No inherited code, downloaded Python module, notebook, or pickle is executed. Model files are loaded offline from safetensors, with remote code disabled.

The verifier requires four externally held files. Their required SHA-256 values are in `auditlib/data.py` and are checked before analysis.

Preserve the release's within-trial chronological fixation order.

The local model directories must match `model_manifest.json`. ## Verification

Run `python verify.py --synthetic-only` for synthetic invariants. For the complete reproduction, supply the four input paths, both model directories, and a new output directory:

```sh
python verify.py --aggregate inputs/all_measures.csv \
  --reading-times inputs/eyetracking.RT.txt \
  --fixations inputs/eyetracking.fix.txt --pos inputs/stimuli_pos.txt \
  --gpt2 models/gpt2 --gpt-neo models/gpt-neo-125m --output results/run1
```

These are example relative paths, not bundled data. Inputs must remain outside the output directory. All failed checks produce a nonzero exit. The complete command reruns model inference, checks every multi-token target plus ten fixed controls with prefix-at-a-time inference, reconstructs the eye-time means, and runs all 16 original analysis cells over 20 fixed sentence partitions, including their stratum and deletion checks. It then runs the complete incremental-score extension: 1,600 nuisance-model and 6,400 full-model fold fits, 320 unique pooled baselines, and 320 four-construction comparisons. The extension must recover the original row-based/keyed endpoint losses within 10^-9 ms². It never drops a negative incremental value to produce a pass.

The run writes reconstructed score caches for local reuse, `results.json`, `incremental_fold_diagnostics.json` (8,000 aggregate fit records), and `incremental_fold_memberships.json` (200 count/hash records). No word text, participant records, individual response rows, or occurrence-ID lists are exported. The result record binds the diagnostic files by filename and hash. The caches are newly computed, row-aligned numerical arrays; they are ignored by Git and are not included in this repository.

`--reuse-scores` explicitly reuses only caches generated by this verifier, after digest, model, input and numerical reconstruction checks. That mode reports cache reuse and is not fresh neural inference. It still recomputes all regression results. Do not treat a hash as independent verification of a result's scientific interpretation.

Export the complete aggregate tables and two original diagnostic figures from a verified run:

```sh
python export_results.py results/run1/results.json --output results/figures1
```

The figures are written as PDF, PNG and JPEG, with their result and asset hashes in `figure_manifest.json`. The three original tables retain all 16 overall comparisons, 32 strata and 32 deletion refits. Five additional CSVs contain the extension's 320 distinct baselines (`en_incremental_baselines`), 1,280 condition/block values (`en_incremental_scores`), 320 joint changes (`en_incremental_changes`), 320 sets of path contrasts (`en_incremental_paths`), and all 16 condition summaries (`en_incremental_summary`). Baseline values repeated beside different full-model conditions are the same references, not new baseline fits or independent replications. Undefined normalized values have a blank CSV field and an explicit false defined flag; JSON uses null.

The figures display the original canonical-score diagnostics; a manuscript may use complete tables instead. All partition ranges are descriptive sensitivities, not confidence intervals. Rendering does not itself certify visual quality. An older run without the extension must be rerun with this verifier before exporting the new central results.

The full inference tolerance is 0.001 nat. In the exploratory development work, one float32 GPT-Neo prefix comparison exceeded the initial 0.0001-nat threshold. A bounded float64 check justified the declared tolerance; the entire corpus was not rerun in float64. The present release does not hide that precision limitation or silently loosen a failing threshold.

## Analysis target and limits

The outcomes are zero-inclusive means over available readers, in milliseconds. OLS uses the identity mean link and a unit surprisal exponent. Covariates are current length, natural-log frequency and relative position; all three pairwise interactions; preceding length and frequency; and current/preceding surprisal. Training data alone determine scaling. Sentence-disjoint folds are shared within each contrast. The joint correction changes both the position block and the complete predecessor block; it does not isolate a causal spillover-surprisal effect.

The extension crosses row-based/keyed position (P=0/1) with row-based/keyed predecessor (L=0/1). Position includes its normalization and interactions; predecessor includes length, frequency and, in the full model, surprisal. Let N(P,L) be the nine-column covariate-only MSE and F(P,L) the eleven-column full-model MSE. The same nine standardized nuisance columns enter both models. Incremental value is I=N−F, and its joint change is I11−I00. The exact bookkeeping relation is F00−F11=(N00−N11)+(I11−I00). I/N is undefined when N=0.

Positive path contrasts mean lower loss for N/F and higher incremental value for I. Nonadditivity is the position contrast at L1 minus that at L0, equal to the predecessor contrast at P1 minus that at P0. Both paths are reported; they are not unique causal shares. The fixed result includes increased incremental value in all 160 all-word comparisons and decreased value in 58 of 160 content-word comparisons. There are three negative fully keyed I values. Those finite patterns coexist with the positive total-model joint gains and the separate eight adverse flagged-content reference strata.

The common lag-eligible samples contain 1,104 all-word and 510 content-word observations. Content status follows an explicit noun/adjective/adverb/verb Penn-tag rule, including all VB tags. Predecessors are constructed before word selection. The primary results are finite descriptive loss comparisons. Twenty dependent partitions are not twenty independent experiments or population confidence intervals. Refit-and-resplit deletions differ from fixed-prediction sentence omissions. See `RESULT_MAP.md` for claim coverage.
